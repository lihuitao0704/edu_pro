# Four-Store Test Data Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Safely replace configured project test data with a coherent MySQL and Neo4j dataset, clear the configured Redis DB, and leave Milvus untouched.

**Architecture:** Add one explicit refresh CLI which runs read-only preflight checks before its `--confirm` mutation path. It uses deterministic factories for every SQLAlchemy-mapped application table, imports Neo4j only after MySQL commit, and verifies MySQL, Redis, and Neo4j outcomes before returning success.

**Tech Stack:** Python 3.11, SQLAlchemy reflection/ORM, PyMySQL, redis.asyncio, Neo4j async driver, pytest.

## Global Constraints

- Read target identities only from `get_settings()`; never print credentials.
- Retain schema, indexes, and constraints; mutate data only.
- MySQL: every discovered application table must have at least 100 rows after success.
- Redis: use `FLUSHDB` only on `settings.redis.db`; never call `FLUSHALL`.
- Neo4j: clear/rebuild only `settings.neo4j.database`.
- Milvus: do not import its client or call any Milvus API.
- All destructive work requires `python scripts/refresh_test_data.py --confirm`.

def preflight_mysql(connection) -> list[str]:
    with connection.cursor() as cursor:
        cursor.execute("SELECT DATABASE()")
        assert cursor.fetchone()[0] == settings.mysql.database
        cursor.execute("SELECT table_name FROM information_schema.tables WHERE table_schema=%s AND table_type='BASE TABLE'", (settings.mysql.database,))
        return [row[0] for row in cursor.fetchall()]

def refresh_mysql(connection, table_names: list[str]) -> dict[str, int]:
    disable_foreign_key_checks(connection)
    try:
        delete_all_project_rows(connection, table_names)
        insert_dataset_in_parent_first_order(connection, build_dataset())
        connection.commit()
    except Exception:
        connection.rollback()
        raise
    finally:
        enable_foreign_key_checks(connection)
    return verify_mysql_counts(connection, table_names)
```

Use `DELETE FROM` in the reverse of the factory parent order and `ALTER TABLE ... AUTO_INCREMENT = 1` only after a table has been emptied. Do not use `DROP`, `TRUNCATE`, or schema DDL. Abort if the discovered MySQL table set is not exactly covered by the factory map.

async def clear_redis_db(redis) -> None:
    await redis.flushdb()

async def rebuild_neo4j(driver) -> None:
    async with driver.session(database=settings.neo4j.database) as session:
        await session.run("MATCH (n) DETACH DELETE n")
    await neo4j_import.create_indexes(driver)
    await neo4j_import.import_products(driver)
    await neo4j_import.import_customers(driver)
    await neo4j_import.import_holdings(driver)
    await neo4j_import.import_transactions(driver)
```
