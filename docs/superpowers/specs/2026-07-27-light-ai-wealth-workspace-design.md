# 浅色 AI 财富工作台设计

**状态：** 已获视觉方向确认，待规格复核后实施

## 目标

将现有 Vue 3 金融智能投顾平台升级为全站统一的浅色高级产品界面：信息清晰、业务可信、支持 AI 协作，并在不改变现有接口和权限边界的前提下改善体验。

## 产品与用户

- **产品形态：** 金融投顾与运营 SaaS 控制台。
- **核心用户：** 投顾、运营人员、风控人员及终端客户。
- **使用场景：** 高频查看数据、识别风险、处理业务、与 AI 助手协同。
- **视觉参照：** Codex 官网的低噪声排版、命令中心式信息分层和克制留白；不复用 OpenAI/Codex 的品牌资产、文案或标识。

## 视觉系统

### 色彩与层次

- 基底使用雾白、暖灰与浅蓝灰，避免大面积纯白。
- 文字使用深石墨；主操作使用深靛蓝；成功、警告和风险状态使用低饱和的语义色。
- 背景使用低透明度的蓝紫渐变网格、细微噪点和柔和光团，始终位于内容之后。
- 卡片使用半透明白色、1px 低对比边框、轻阴影与小面积 `backdrop-filter`，避免玻璃效果泛滥。

### 排版与空间

- 采用无衬线中文优先字体与等宽数字/状态字样；标题强调字重和尺寸，不用装饰性字体。
- 采用 4/8px 空间节奏；桌面主内容最大宽度与响应式边距随断点调整。
- 圆角克制：常规控件 8px，面板 12px，不使用大圆角堆叠。

### 图标与组件

- 导航和操作使用统一的线性 SVG 图标，禁止以 Emoji 充当功能图标。
- 建立 shadcn 风格的基础组件外观：Button、Input、Card、Dialog、Toast、Empty State、Skeleton、Badge、Table。
- 所有可点击元素提供可见焦点、悬浮与禁用状态；表单保留可读标签和就近的错误反馈。

## 应用结构

### 全局框架

- 左侧导航可折叠，在窄屏切换为抽屉式导航。
- 顶部上下文栏承载当前页面、全局搜索入口、通知和用户菜单。
- 页面统一为：页面标题及上下文操作、Bento 指标或摘要、主要工作区、次级洞察与空/错/加载状态。

### 页面改造范围

- **登录与注册：** 浅色品牌入口、低干扰氛围背景及系统就绪感。
- **仪表盘：** “今日态势”Bento 总览、风险焦点、Agent 执行轨迹和经营图表。
- **AI 对话：** 左侧上下文/会话，右侧可阅读的对话流和结构化建议卡；流式/加载状态清晰可见。
- **投顾工作台、客户画像、风控、运营、分析、知识库：** 使用统一标题区、筛选工具条、数据面板和详情抽屉/弹窗模式。

## 动效与开场

- 首次打开应用显示约 1.2 秒的开场：细线网格、品牌标记、系统状态依次出现，然后淡出进入应用。
- 页面内容使用 180–320ms 的透明度与位移进入；列表/卡片可做短距离错峰出现。
- 悬浮、按压、筛选、抽屉和弹窗采用 150–300ms 自然缓动，只动画 `opacity` 和 `transform`。
- 读取 `prefers-reduced-motion`，减少动效模式下取消开场、滚动进入和连续装饰动画。
- 不使用常驻装饰性动效；不引入会干扰数据密度的 Three.js 场景。氛围元素优先 CSS 实现。

## 响应式与可访问性

- 验证 375px、768px、1024px、1440px；Bento 网格在小屏按优先级堆叠。
- 正文对比度不低于 4.5:1，辅助文本不低于 3:1。
- 键盘焦点顺序与视觉顺序一致，弹窗具备焦点管理，错误使用 `role=alert` 或 `aria-live`。
- 图表、风险状态和标签不只依赖颜色表达。

## 技术边界

- 继续使用 Vue 3、Vite、TypeScript、Vue Router、Pinia、Element Plus 与 ECharts。
- 不替换后端 API、认证、权限、路由地址和现有数据契约。
- 不新增需要网络下载的重型动画或 3D 依赖；在现有依赖内以 CSS/Vue 过渡实现动效。
- 新增行为以 Vitest 测试优先；既有测试保持通过。

## 验收标准

- 全站的导航、表面、表单、表格、状态组件与反馈有一致的浅色产品化语言。
- 首次进入有可跳过/可因减少动效偏好而省略的开场体验。
- 各关键页面在桌面和移动断点无横向溢出，加载、空、错误、成功状态明确。
- 构建、类型检查和既有前端测试通过。
